Create a GitHub token

      
Open GitHub fine-grained token settings ↗

      
    
        
  1. On GitHub, open Settings → Developer settings → Personal access tokens → Fine-grained tokens, then create a token.
    2. 
        
  2. Choose the account or organization that owns your vault, and restrict the token to only the repository that contains that vault.
    3. 
        
  3. Under repository permissions, set Contents to Read and write. GitHub’s required repository metadata permission can remain read-only.
    4. 
        
  4. Choose an expiration that suits you. GitHub shows the token only when it is created, so save it in a trusted password manager before leaving that page.
    5. 
        
  5. Paste the token into Pleronic’s Settings and save your vault settings.
    6. 
      

      
Access scope: GitHub fine-grained tokens can be restricted to a repository, but not to a folder within it. Pleronic needs repository Contents access to browse, read, and edit vault notes.

      
Where it is stored: Pleronic stores the token in this browser profile’s persistent localStorage on this device—not in temporary sessionStorage. Anyone who can use this browser profile may be able to use the token. Pleronic has no app server and sends the token directly to GitHub. Disconnecting removes the local settings; revoke the token in GitHub to invalidate it.
